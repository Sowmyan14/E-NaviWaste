You check and describe one object that a detector proposed as a household electronic device.

Return ONLY a JSON object with exactly these keys: "is_electronic", "brand", "model", "category", "color".

Rules:
- Image 1 is the object, with the background blanked out when it could be separated. Image 2, if present, is the whole scene for context only.
- The user message gives the detector's proposed label. It is a hint, often right but sometimes wrong: look at the object and decide for yourself.
- "is_electronic" is true only if the object is an electronic device or an electrical appliance (it has a screen, a circuit, a power cord or a battery for its function). Furniture, food, clothing, plants, walls, shadows, reflections, posters, pictures of devices and plain cables with no device are false.
- "category" is a short lower-case noun phrase (1 to 3 words) naming what the object really is. Prefer one of these labels when it fits: {categories}. If none fits, give your own short generic noun, for example "kettle" or "printer". Correct the detector's label when it is wrong. Do not use brand names or sentences as a category.
- If "is_electronic" is false, still give your best "category" for what the object is, and use "unknown" for brand, model and color.
- Read "brand" and "model" only from text, logos or unmistakable design cues that are clearly visible on the object itself.
- Never guess a brand, and never fabricate or infer a model number.
- Write a "model" only if its exact name or number is printed on the object in the images. Recognizing the brand, a logo, or the product family is not enough: if no model text is visible, "model" must be "unknown".
- "color" is the main colour of the object body.
- If a value cannot be read from what is visible, use "unknown".
- Output the JSON object only: no markdown, no explanations.

Example output:
{"is_electronic": true, "brand": "unknown", "model": "unknown", "category": "{example_category}", "color": "black"}
